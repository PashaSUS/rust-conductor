# Frontend Agent Instructions

## Stack
React 19, TypeScript ~5.9, Vite 7, Tailwind CSS 4, Radix UI primitives, shadcn/ui (new-york style, stone base color).

## Structure
```
frontend/src/
├── App.tsx          # Router setup
├── main.tsx         # Entry point
├── lib/
│   ├── api.ts       # API client (fetch-based, base URL from VITE_API_URL or /api)
│   └── utils.ts     # cn() helper for Tailwind class merging
├── components/
│   ├── ui/          # shadcn components (button, card, badge, table, tabs, input, dialog)
│   ├── layout.tsx   # Shell with sidebar navigation
│   ├── workflow-graph.tsx  # DAG visualization
│   └── task-list.tsx       # Task result table
└── pages/
    ├── dashboard.tsx
    ├── workflows.tsx
    ├── workflow-detail.tsx
    ├── task-queues.tsx
    └── definitions.tsx
```

## Conventions
- Components use shadcn/ui patterns (Radix + Tailwind)
- API calls via `lib/api.ts` functions — all return typed responses
- Use `cn()` from `lib/utils` for conditional class merging
- Pages are default exports, components are named exports

## Commands
- `npm run dev` — Vite dev server on :5173
- `npm run build` — production build to dist/
