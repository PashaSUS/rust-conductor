# Backend Agent Instructions

## Stack
Rust 2021 edition, Actix-web 4, sqlx 0.8 (Postgres), deadpool-redis 0.18, serde 1, chrono 0.4, thiserror 2.

## Adding a New Endpoint
1. Add engine method in `engine/mod.rs` returning `Result<T, EngineError>`
2. Add API handler in appropriate `api/*.rs` file
3. Register route in the module's `configure()` function
4. If new model types needed, add to appropriate `models/*.rs` file — they auto-export via `pub use` in `models/mod.rs`

## Adding a New DB Table
Add `CREATE TABLE IF NOT EXISTS` + indexes to `store/postgres.rs::run_migrations()`

## SQL Conventions
- Use `$1, $2` bind parameters (never interpolate user input)
- Search queries sanitize via `.replace('\'', "")` for ILIKE patterns
- DateTime columns are `TIMESTAMPTZ`
- JSON columns are `JSONB`

## Error Handling
`EngineError` variants: `Database`, `Redis`, `NotFound`, `InvalidState`, `Serde`. Maps to HTTP 404/409/500.

## Testing with cargo
Run `cargo check` after every change. Warnings about unused structs in models are expected (API completeness types).
